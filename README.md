Catch the Ghost is a fun and challenging clicking game that I created using p5.js, a JavaScript library for creative coding and interactive graphics. The objective of the game is to click on the ghost as many times as possible within 30 seconds to earn points. The ghost is constantly vibrating, moving, and changing its position, making it difficult to catch. Every successful click increases the score by one point. I created the game using shapes such as circles and rectangles for the background and characters, random coordinates to make the ghost move, mouse-click detection to register clicks, a scoring system to track points, and a countdown timer to control the 30-second gameplay. Through this project, I learned how to use p5.js to create animations, handle user interactions, work with coordinates, and develop basic game mechanics.
